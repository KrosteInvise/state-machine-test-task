# Симуляция логистического процесса

Тестовое задание: несколько независимых NPC собирают коробки и относят их на склад. Сутки идут непрерывно, день и ночь влияют на мир и на рабочих.

Unity **6000.0.61f1** (6 LTS). Графика примитивы.

## Запуск

1. Открыть проект в Unity 6 LTS.
2. Сцена `Assets/Scenes/Main.unity`.
3. Play.

Параметры симуляции ScriptableObject `Assets/ScriptableObjects/LogisticsSettings.asset`: длина суток, границы дня/ночи, спавн коробок, размер зон, число NPC и скорости.

По умолчанию сутки = 120 секунд, старт в 08:00, ночь с 22:00. Ночь наступает примерно через **70 секунд** Play Mode.

## Архитектура

Системы слабо связаны. Каждая сущность знает свою работу, общий конфиг `LogisticsSettings`, сборка composition root.

| Слой | Ответственность |
|---|---|
| `Bootstrap` | `MainEntryPoint` - только порядок `Init` |
| `Core` | Часы, настройки, свет сцены |
| `Gameplay` | Коробки, склад, NPC и FSM |
| `UI` | Часы и фаза суток |

`Core` не зависит от `Gameplay`. Игровые объекты не стартуют сами через `Awake`: их поднимает точка входа.

```
gameTime.Init(settings);
dayNightLighting.Init(gameTime);
clockHud.Init(gameTime);
boxArea.Init(settings);
warehouse.Init(settings, boxArea);
npcArea.Init(settings, boxArea, warehouse, gameTime);
```

**`GameTime`** это единственный источник правды о времени. Непрерывные 24 часа, скорость из настроек, проверка на `IsNight`, события `DayStarted` / `NightStarted`. Свет и HUD только читают часы, свои таймеры не заводят.

## NPC

У каждого NPC свой экземпляр конечного автомата. Рабочий цикл:

`Idle → FindBox → MoveToBox → PickUp → MoveToWarehouse → DropOff → FindBox`

Если свободной коробки нет, то `Idle`, затем снова поиск. Состояния не знают друг о друге поверх `Npc`: переходы идут через смену состояния на самом персонаже.

Движение `Vector3.MoveTowards` по XZ, без NavMesh. На открытой плоскости препятствий нет, навигацию решил здесь не делать.

## Конкуренция за коробки

Резерв живёт на самой коробке, не в менеджере. `Box.TryReserve(Npc)` отдаёт объект только одному рабочему. Остальные ищут следующую свободную. Сдача на склад возвращает коробку в пул `BoxArea`.

## День и ночь

Сутки в данном случае не вторая стейт-машина. Это фазы часов. рабочий цикл NPC никак с ней не связан.

Ночью задача не сбрасывается: коробку не бросают, состояние автомата не откатывают. Меняется только модификатор:

- скорость (`NpcMoveSpeed` днём, `NpcNightMoveSpeed` ночью);
- цвет NPC;
- свет и небо (`DayNightLighting`);
- подписи и цвет HUD (`ClockHud`).

Переключение сразу на смене фазы. Контраст намеренно сильный, чтобы смену суток было видно без подсказок.
